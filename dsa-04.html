    Strings I

    15 sections · interview-oriented · both themes

    1. Remove Outermost Parentheses

    Difficulty: LOW

    Statement/Hint: Given a valid parentheses string formed by concatenating primitive valid parentheses strings, remove the outermost parentheses of every primitive substring.

    Example: - Input: s = "(()())(())" - Output: "()()()"

    Approach: Balance Counter - A "primitive" substring is a non-empty valid parentheses string that isn't further decomposable - its balance count returns to 0 only at its very end. - Scan left to right tracking an open-count balance: increment on '(', decrement on ')'. Only append '(' to the result when balance > 0 before incrementing, and only append ')' when balance > 1 before decrementing (i.e., skip the character that takes balance to/from 0). - Equivalently: append a character unless it's the opening '(' that takes balance from 0 to 1, or the closing ')' that takes balance from 1 to 0 - those are exactly the "outermost" ones. - O(n) time, O(n) space for the output (or O(1) extra if building in place).

    Time / Space: O(n) time, O(n) space.

    public String removeOuterParentheses(String s) {
 StringBuilder result = new StringBuilder();
 int balance = 0;
 for (char c : s.toCharArray()) {
 if (c == '(') {
 if (balance > 0) result.append(c);
 balance++;
 } else {
 balance--;
 if (balance > 0) result.append(c);
 }
 }
 return result.toString();
}

    2. Reverse Words in a String

    Difficulty: LOW

    Statement/Hint: Given a string containing words separated by spaces (possibly with leading/trailing/multiple spaces), reverse the order of the words.

    Example: - Input: s = " the sky is blue " - Output: "blue is sky the"

    Approach: Split, Reverse, Join - Split the string on whitespace, discarding empty tokens produced by consecutive spaces, leading, or trailing spaces. - Reverse the list of resulting words, then join them with a single space. - Handling the "multiple/leading/trailing spaces" edge case cleanly (rather than naively splitting on a single space character) is the actual point of the problem. - O(n) time and space, where n is the string length.

    Time / Space: O(n) time, O(n) space.

    public String reverseWords(String s) {
 String[] words = s.trim().split("\\s+");
 StringBuilder result = new StringBuilder();
 for (int i = words.length - 1; i >= 0; i--) {
 result.append(words[i]);
 if (i != 0) result.append(" ");
 }
 return result.toString();
}

    3. Largest Odd Number in a String

    Difficulty: LOW

    Statement/Hint: Given a string representing a large non-negative integer, find the largest odd-valued substring prefix (i.e., the longest prefix that ends in an odd digit).

    Example: - Input: s = "52" - Output: "5"

    Approach: Rightmost Odd Digit Scan - The largest odd number obtainable is always some prefix of the original digit string - dropping trailing digits only shrinks the number, so the best answer is the longest valid prefix. - Scan from the last character backward and find the first (rightmost) odd digit; the prefix ending at that index is the answer. - If no digit is odd, the answer is an empty string (no odd number can be formed). - O(n) time, O(1) extra space (excluding the returned substring).

    Time / Space: O(n) time, O(1) space.

    public String largestOddNumber(String s) {
 for (int i = s.length() - 1; i >= 0; i--) {
 if ((s.charAt(i) - '0') % 2 == 1) return s.substring(0, i + 1);
 }
 return "";
}

    4. Longest Common Prefix

    Difficulty: MEDIUM

    Statement/Hint: Find the longest common prefix string amongst an array of strings.

    Example: - Input: strs = ["flower","flow","flight"] - Output: "fl"

    Approach: Horizontal Scan (Shrinking Prefix) - Take the first string as an initial candidate prefix, then repeatedly shrink it by comparing against each subsequent string until it's actually a prefix of that string. - For each string, trim the candidate prefix (remove characters from the end) while it doesn't match the start of that string; stop early if the prefix ever becomes empty. - Alternative: compare characters column-by-column across all strings simultaneously, stopping at the first mismatch or the shortest string's length - same complexity, avoids repeated substring trimming. - O(S) time where S is the sum of all characters across strings (worst case), O(1) extra space beyond the output.

    Time / Space: O(S) time, O(1) space.

    public String longestCommonPrefix(String[] strs) {
 if (strs.length == 0) return "";
 String prefix = strs[0];
 for (int i = 1; i < strs.length; i++) {
 while (!strs[i].startsWith(prefix)) {
 prefix = prefix.substring(0, prefix.length() - 1);
 if (prefix.isEmpty()) return "";
 }
 }
 return prefix;
}

    5. Isomorphic Strings

    Difficulty: MEDIUM

    Statement/Hint: Determine if two strings are isomorphic - characters in one string can be consistently mapped to characters in the other, preserving order and one-to-one mapping.

    Example: - Input: s = "egg", t = "add" - Output: true

    Approach: Two-Way Hash Map - Maintain two hash maps: one mapping characters from s to t, and one mapping characters from t to s (both directions must be consistent). - For each position i, if s[i] already has a mapping, it must equal t[i]; if t[i] already has a mapping, it must equal s[i]; otherwise create both mappings. - Checking only one direction (s -> t) is a common bug - it misses cases like s = "ab", t = "aa" where 'a' and 'b' would both incorrectly map to 'a'. - O(n) time, O(1) extra space (bounded by the character set size, typically 256).

    Time / Space: O(n) time, O(1) space.

    public boolean isIsomorphic(String s, String t) {
 if (s.length() != t.length()) return false;
 Map<Character, Character> mapST = new HashMap<>();
 Map<Character, Character> mapTS = new HashMap<>();
 for (int i = 0; i < s.length(); i++) {
 char a = s.charAt(i), b = t.charAt(i);
 if (mapST.containsKey(a) && mapST.get(a) != b) return false;
 if (mapTS.containsKey(b) && mapTS.get(b) != a) return false;
 mapST.put(a, b);
 mapTS.put(b, a);
 }
 return true;
}

    6. String Rotation

    Difficulty: LOW

    Statement/Hint: Given two strings, check whether one is a rotation of the other (e.g. 'waterbottle' is a rotation of 'erbottlewat').

    Example: - Input: s1 = "waterbottle", s2 = "erbottlewat" - Output: true

    Approach: Concatenation Trick - If s2 is a rotation of s1, then s2 must be a substring of s1 concatenated with itself (s1 + s1) - rotating splits s1 at some point and swaps the two halves, and s1 + s1 contains every possible split. - First check the lengths are equal (a rotation can't change length); if not, return false immediately. - Then just check if s2 is a substring of s1 + s1, using any standard substring search. - O(n) time with an efficient substring search (like KMP) - O(n^2) with a naive substring check, but n is usually small enough that this doesn't matter in interviews.

    Time / Space: O(n) time, O(n) space.

    public boolean isRotation(String s1, String s2) {
 if (s1.length() != s2.length()) return false;
 String doubled = s1 + s1;
 return doubled.contains(s2);
}

    7. Valid Anagram

    Difficulty: LOW

    Statement/Hint: Determine whether two strings are anagrams of each other (same characters with the same frequencies, possibly reordered).

    Example: - Input: s = "anagram", t = "nagaram" - Output: true

    Approach: Frequency Counting - If the lengths differ, they can't be anagrams - check this first as a cheap early exit. - Count character frequencies in one string (e.g. an int[26] array for lowercase letters, or a hash map for a general character set), then decrement counts while scanning the second string. - If any count goes negative, or any count is nonzero at the end, the strings aren't anagrams. - O(n) time, O(1) extra space for a fixed alphabet (O(k) for k distinct characters in the general case) - avoids the O(n log n) cost of sorting both strings and comparing.

    Time / Space: O(n) time, O(1) space.

    public boolean isAnagram(String s, String t) {
 if (s.length() != t.length()) return false;
 int[] count = new int[26];
 for (char c : s.toCharArray()) count[c - 'a']++;
 for (char c : t.toCharArray()) count[c - 'a']--;
 for (int c : count) if (c != 0) return false;
 return true;
}

    8. Sort Characters by Frequency

    Difficulty: MEDIUM

    Statement/Hint: Given a string, sort its characters in decreasing order of frequency (ties can be in any order).

    Example: - Input: s = "tree" - Output: "eert"

    Approach: Frequency Count + Bucket Sort - Count the frequency of each character using a hash map (or a fixed-size array for a known alphabet). - Group characters by frequency using a bucket array indexed by frequency (frequencies range from 0 to n), or use a max-heap keyed by frequency for a simpler priority-based approach. - Walk buckets from highest frequency to lowest (or repeatedly pop from the max-heap), appending each character repeated by its count to the result. - O(n + k) time with bucket sort (k = distinct characters, effectively O(n)), or O(n log k) with a heap; O(n) space either way.

    Time / Space: O(n) time, O(n) space.

    public String frequencySort(String s) {
 Map<Character, Integer> freq = new HashMap<>();
 for (char c : s.toCharArray()) freq.merge(c, 1, Integer::sum);
 int n = s.length();
 List<Character>[] buckets = new List[n + 1];
 for (int i = 0; i <= n; i++) buckets[i] = new ArrayList<>();
 for (Map.Entry<Character, Integer> e : freq.entrySet())
 buckets[e.getValue()].add(e.getKey());
 StringBuilder result = new StringBuilder();
 for (int cnt = n; cnt >= 1; cnt--) {
 for (char ch : buckets[cnt]) {
 for (int i = 0; i < cnt; i++) result.append(ch);
 }
 }
 return result.toString();
}

    9. Maximum Nesting Depth of Parentheses

    Difficulty: LOW

    Statement/Hint: Given a valid parentheses string (possibly with other characters), find the maximum nesting depth of the parentheses.

    Example: - Input: s = "(1+(2*3)+((8)/4))+1" - Output: 3

    Approach: Running Depth Counter - Scan left to right maintaining a running depth counter: increment on '(', decrement on ')'. - Track the maximum value the depth counter reaches at any point - that's the answer. - Non-parenthesis characters are simply skipped/ignored; they don't affect the depth counter. - O(n) time, O(1) space.

    Time / Space: O(n) time, O(1) space.

    public int maxDepth(String s) {
 int depth = 0, maxD = 0;
 for (char c : s.toCharArray()) {
 if (c == '(') depth++;
 else if (c == ')') depth--;
 maxD = Math.max(maxD, depth);
 }
 return maxD;
}

    10. Roman to Integer

    Difficulty: LOW

    Statement/Hint: Convert a Roman numeral string to its integer value.

    Example: - Input: s = "MCMXCIV" - Output: 1994

    Approach: Left-to-Right Scan with Lookahead - Map each Roman symbol to its value (I=1, V=5, X=10, L=50, C=100, D=500, M=1000). - Scan left to right: if a symbol's value is less than the value of the symbol immediately to its right, subtract it; otherwise add it. This naturally handles subtractive notation like "IV" (4) or "IX" (9). - Comparing each symbol to the next avoids needing special-cased pairs for every subtractive combination (IV, IX, XL, XC, CD, CM). - O(n) time, O(1) space.

    Time / Space: O(n) time, O(1) space.

    public int romanToInt(String s) {
 Map<Character, Integer> val = Map.of('I', 1, 'V', 5, 'X', 10, 'L', 50, 'C', 100, 'D', 500, 'M', 1000);
 int result = 0;
 for (int i = 0; i < s.length(); i++) {
 if (i + 1 < s.length() && val.get(s.charAt(i)) < val.get(s.charAt(i + 1)))
 result -= val.get(s.charAt(i));
 else
 result += val.get(s.charAt(i));
 }
 return result;
}

    11. String to Integer (atoi)

    Difficulty: MEDIUM

    Statement/Hint: Implement atoi: convert a string to a 32-bit signed integer, handling leading whitespace, an optional sign, leading zeros, and clamping to INT_MIN/INT_MAX on overflow, or returning 0 if no valid conversion can be performed.

    Example: - Input: s = " -42" - Output: -42

    Approach: Character-by-Character Parse with Overflow Guard - Skip leading whitespace, then check for an optional '+' or '-' sign. - Consume consecutive digit characters, building up the numeric value; stop at the first non-digit character (or end of string). - After each digit is added, check if the accumulated value would exceed INT_MAX (or go below INT_MIN if negative) - clamp and return immediately if so, rather than letting the accumulator overflow. - If no digits were found at all (e.g. the string starts with a letter), return 0. - O(n) time, O(1) space. The clamping-on-overflow logic (checked before each multiply/add, not after) is the main source of bugs.

    Time / Space: O(n) time, O(1) space.

    public int myAtoi(String s) {
 int i = 0, n = s.length();
 while (i < n && s.charAt(i) == ' ') i++;
 int sign = 1;
 if (i < n && (s.charAt(i) == '+' || s.charAt(i) == '-')) {
 if (s.charAt(i) == '-') sign = -1;
 i++;
 }
 long result = 0;
 while (i < n && Character.isDigit(s.charAt(i))) {
 result = result * 10 + (s.charAt(i) - '0');
 if (result * sign > Integer.MAX_VALUE) return Integer.MAX_VALUE;
 if (result * sign < Integer.MIN_VALUE) return Integer.MIN_VALUE;
 i++;
 }
 return (int) (result * sign);
}

    12. Count Substrings with Exactly K Distinct Characters

    Difficulty: MEDIUM

    Statement/Hint: Count the number of substrings of a string that contain exactly K distinct characters.

    Example: - Input: s = "abcba", K = 2 - Output: 7

    Approach: At-Most-K Sliding Window Trick - Direct counting for "exactly K" is awkward, but "at most K" is a clean sliding window - so compute countAtMost(K) - countAtMost(K-1), since exactly-K substrings = (substrings with <= K distinct) minus (substrings with <= K-1 distinct). - countAtMost(K) uses a sliding window with a frequency map: expand the right pointer, and while the window has more than K distinct characters, shrink from the left. For each valid right position, add (right - left + 1) to the count - that's the number of substrings ending at right with <= K distinct characters. - This "exactly = atMost(K) - atMost(K-1)" transformation is a reusable trick for many "exactly K" sliding-window problems. - O(n) time (each pointer moves forward at most n times, across both calls), O(k) space for the frequency map.

    Time / Space: O(n) time, O(k) space.

    private int atMostK(String s, int k) {
 Map<Character, Integer> freq = new HashMap<>();
 int left = 0, count = 0;
 for (int right = 0; right < s.length(); right++) {
 freq.merge(s.charAt(right), 1, Integer::sum);
 while (freq.size() > k) {
 char c = s.charAt(left);
 freq.put(c, freq.get(c) - 1);
 if (freq.get(c) == 0) freq.remove(c);
 left++;
 }
 count += right - left + 1;
 }
 return count;
}

public int countSubstringsWithKDistinct(String s, int k) {
 return atMostK(s, k) - atMostK(s, k - 1);
}

    13. Longest Palindromic Substring

    Difficulty: MEDIUM

    Statement/Hint: Find the longest palindromic substring within a given string.

    Example: - Input: s = "babad" - Output: "bab" (or "aba")

    Approach: Expand Around Center - Expand Around Center: for each possible center (there are 2n-1 centers - n single-character centers and n-1 between-character centers for even-length palindromes), expand outward while characters match, tracking the longest palindrome found. - This avoids the O(n^2) space of a DP table approach while staying simple to reason about - O(n^2) time, O(1) extra space. - Manacher's Algorithm solves this in O(n) time but is complex to implement correctly and rarely expected unless explicitly asked for the optimal solution. - Handle both odd-length (single center) and even-length (center between two characters) cases by calling the same expand function with (i, i) and (i, i+1) starting pairs.

    Time / Space: O(n^2) time, O(1) space.

    public String longestPalindrome(String s) {
 int[] best = {0, 0};
 for (int i = 0; i < s.length(); i++) {
 expand(s, i, i, best);
 expand(s, i, i + 1, best);
 }
 return s.substring(best[0], best[0] + best[1]);
}

private void expand(String s, int l, int r, int[] best) {
 while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
 l--;
 r++;
 }
 if (r - l - 1 > best[1]) {
 best[1] = r - l - 1;
 best[0] = l + 1;
 }
}

    14. Sum of Beauty of All Substrings

    Difficulty: LOW

    Statement/Hint: The 'beauty' of a string is defined as (max frequency of any character) - (min frequency of any character) in it. Find the sum of beauty over all substrings of a given string.

    Example: - Input: s = "aabcb" - Output: 5

    Approach: Incremental Frequency Count per Substring - Brute force: for every starting index, extend the substring one character at a time, maintaining a frequency array of size 26 that's updated incrementally as the substring grows. - For each extended substring, scan the frequency array to find the current max and min (nonzero) frequency, compute their difference, and add it to the running total. - Incrementally updating the frequency count (rather than recomputing it from scratch for each substring) avoids an extra O(n) factor from recounting; a fixed 26-size array keeps the max/min scan O(26) = O(1). - O(n^2 * 26) time overall (effectively O(n^2)), O(26) space - no known better-than-quadratic approach since every substring's beauty is genuinely independent information.

    Time / Space: O(n^2) time, O(1) space.

    public int beautySum(String s) {
 int n = s.length(), total = 0;
 for (int i = 0; i < n; i++) {
 int[] freq = new int[26];
 for (int j = i; j < n; j++) {
 freq[s.charAt(j) - 'a']++;
 int maxF = 0, minF = Integer.MAX_VALUE;
 for (int f : freq) {
 if (f > 0) {
 maxF = Math.max(maxF, f);
 minF = Math.min(minF, f);
 }
 }
 total += maxF - minF;
 }
 }
 return total;
}

    15. Reverse Words in a String III

    Difficulty: LOW

    Statement/Hint: Given a string of space-separated words, reverse the characters within each word while keeping the words in their original order.

    Example: - Input: s = "Let's take LeetCode contest" - Output: "s'teL ekat edoCteeL tsetnoc"

    Approach: Split, Reverse Each Word, Join - Split the string into words on spaces, reverse each word's characters individually (e.g. using two-pointer swap or a built-in reverse), then join the reversed words back together with spaces in their original order. - This differs from "reverse word order" problems - the words stay in place, only their internal character sequence flips. - O(n) time, O(n) space for the output (or O(1) extra if reversing in place within a mutable character array).

    Time / Space: O(n) time, O(n) space.

    public String reverseWordsInString(String s) {
 String[] words = s.split(" ");
 StringBuilder result = new StringBuilder();
 for (String word : words) {
 result.append(new StringBuilder(word).reverse()).append(" ");
 }
 return result.toString().trim();
}
